# CLS-ER + SD²-SNN：把 CLS-ER 的海马体–新皮层机制改造成脉冲版本

把 **CLS-ER**（Arani et al., ICLR 2022）的互补学习系统（CLS）机制，移植到
**SD²-SNN** 的脉冲骨干上，并系统性地测量"脉冲基底到底付了多少代价"。

**关键点：这不是"换个 backbone"就完事。** CLS-ER 的每一个机制都隐含 ANN 假设
（连续 logits、BN 只是统计、模型只有一个时刻的输出、激活不会崩塌），而这些假设在
脉冲网络里全部不成立。本项目逐条识别并替换（§2），再逐一检验哪些改动真的有用。

```
CLS-ER 的"学什么"                    SD²-SNN 的"用什么学"
├── working / stable / plastic        ├── LIF + ATan 替代梯度
├── 双语义记忆（海马体 / 新皮层）       ├── Spiking-ResNet-18，T 步直接编码
├── 一致性约束（选哪个记忆监督）        ├── 时间平均放电率 → 分类头
├── reservoir 回放                     └── 可选：W≈UVᵀ / KL 稀疏 / 稀疏子空间
└── 任务无关、无 task-id
```

## 结果速览（Seq-CIFAR-10，5 任务 × 2 类，buffer 500，单 seed）

| 配置 | class-IL | task-IL | F_cil | 算力 | 相对 SNN 基线 |
|---|---|---|---|---|---|
| ANN 口径（硬选择 + logit MSE + 只 EMA 参数） | 39.50 | 80.36 | 52.36 | — | −18.0 |
| SNN 原生（软门控 + 率域 KL + 整状态 EMA） | 57.51 | 88.98 | 33.49 | 1.00× | — |
| ＋ **固定正交分类头**（PS-SNN 思路） | **61.37** | 90.22 | 31.39 | **0.98×** | **+3.86** |
| ＋ PLIF（每层可学习 τ，仅 +17 参数） | 59.66 | 91.55 | 33.49 | 1.51× | +2.15 |
| ＋ T=8 | 58.80 | 90.28 | 33.27 | 2.08× | +1.29 |

| — 失败的方向（见 §7h/§7i） | | | | | |
| 时序蒸馏 step / soft-DTW | 57.05 / 54.70 | 89.72 / 87.08 | 34.53 / 33.03 | 1.16× / 1.35× | −0.46 / −2.81 |

**归因**（同参数量、同训练预算、同一套 CLS-ER 机制，只换基底）：

```
论文 CLS-ER（ANN, 50 epochs）        75.22   ← 官方代码，不是我们能复现的范围
  −9.66   ⚠️ 不是"资源不够"，是"我们的重实现与官方实现的差距"（见下）
我们的 ANN（25 epochs, 2.80 M）      65.56
  −2.83   脉冲基底（原始基线时为 8.05，PLIF+T=8 补回 65%）
我们的 SNN（PLIF + T=8）             62.73
```

> ### 重要：这不是一次成功的复现
>
> 我们**没有**复现 CLS-ER 的 75.22。核对官方仓库（`CLS-ER/`）后，找到了六处与官方调优
> 配置的偏差，以及两处代码层面的结构差异：
>
> | 超参 | 官方（`utils/best_args.py`, buffer 500） | 我们 |
> |---|---|---|
> | `reg_weight` | 0.15 | 0.75 |
> | `minibatch_size`（回放） | **32**（占 batch 一半） | 10（24%） |
> | `stable_model_update_freq` | **0.1** | 1.0 |
> | `plastic_model_update_freq` | 0.9 | 1.0 |
> | `plastic_model_alpha` | **0.999** | 0.99 |
> | 优化器 | **SGD lr=0.1，无 momentum、无 wd、无 scheduler** | AdamW 1e-3 / cosine |
>
> | 代码结构 | 官方 | 我们 |
> |---|---|---|
> | 记忆模型的 BN | **train 模式**（用 batch 统计量），只 EMA 参数 | eval 模式（用 running stats），必须整状态 EMA |
> | 学习率调度 | **没有 scheduler**（恒定 lr） | 每个任务内 cosine 衰减到 0 |
>
> 把官方配方移植进我们的实现，三种变体分别得到 26.22 / 33.42 / 27.44（全部崩溃），说明
> **某处差异还没定位**。既然官方代码本身就能给出 75.22，继续在我们的实现里追这个数字没有
> 信息增量——所以本项目**不做复现声明**。
>
> **本文所有结论都只在"同一实现内部"成立**：脉冲 vs 稠密的 2.83 点、PLIF+T=8 的 +5.22、
> 固定头的 +3.86、十一条机制类改动的无效、四种"补资源"的失败。这些比较不受上面任何偏差影响。

## 这个仓库是什么（以及不是什么）

**是**：

- 一份**完整可复现**的 SNN 持续学习实现（20 个 Python 文件、约 3500 行、35 项自检）；
- 一份**系统的消融记录**：十种针对"遗忘机制"的改动全部为零或负，并给出机制层面的诊断；
- 一个**可复用的对照协议**：用同参数量的稠密骨干把"脉冲代价"从"预算代价"里分离出来；
- 若干**静默 bug 的案例**（梯度被 detach、跨任务学习率继承、原型 EMA 在旋转空间抵消），都配了回归测试。

**不是**：

- **不是一个新方法。** 全部组件（CLS-ER、PLIF、直接编码、k-WTA）都来自已有工作；
- **不是一篇复现。** 官方代码给 75.22；我们的重实现是 65.56（ANN）/ 62.73（SNN）。
  六处超参偏差 + 两处结构差异已定位（见顶部“重要：这不是一次成功的复现”），但**没有
  收敛到官方数字**，所以本项目不做复现声明、不与论文横向比较；
- **不是 SOTA。** 62.73 只相当于 ER 水平之上 5 点，低于同期 SNN-CL 工作（如 STAER）；
- **不是多 seed 结论。** 单 seed，2 点以内的差异不应解读；
- **不是在标准协议下的比较。** 骨干是 width-32（2.80 M）而非官方的 nf=64（11.2 M），
  只跑 seq-CIFAR-10。

## 2. 五处必须改造的机制（本项目的核心）

### ① 只 EMA 参数 → **整状态 EMA**

* **ANN 假设**：模型函数只由权重决定，所以"慢速权重副本"就是一个合法的记忆。
* **SNN 现实**：函数由 `(W, BN running stats, v_threshold, τ)` 共同决定。官方 CLS-ER
  只做 `para.mul_(α).add_(1-α, param)`，BN 统计量停在初始化副本上。在脉冲网里
  **BN 统计决定了放电率分布**，于是"记忆"的放电率与真实模型系统性错位，
  它给出的 logits 是错的。
* **改造**：`memories._ema_into` 同时对参数、BN buffers、神经元阈值做同一个 α 的 EMA。
* 代码：`ema_buffers=True`（默认开）。
* 验证：`test_full_state_ema` 检查 BN 均值与 `v_threshold` 都按 α 移动。

### ② 硬选择（按真值类置信度 argmax）→ **软门控**

* **ANN 假设**：softmax 置信度是可靠的，逐样本二选一是稳定操作。
* **SNN 现实**：logits 来自 T 步的平均放电率，T 小的时候估计方差 ~ r(1−r)/T。
  逐样本比较两个"都很噪"的置信度，硬 argmax 会被噪声主导。
* 实测：在训练不足/记忆尚未分化的阶段，硬选择下 `frac_stable` 会被钉在 **0.000**
  （stable 记忆形同失效）；训练充分后它回到 0.2–0.7，说明这个判据本身是**不稳定**的，
  而不是"确定性有效"。
* **改造**：`w = σ(β·(c_s − c_p))`，`z_sel = w·z_s + (1−w)·z_p`；β→∞ 退化为原版硬选择。
  更重要的是：软门控把约束强度与该样本上两个记忆的**实际分歧**挂钩
  （`w ∝ |c_s − c_p|`），而不是像原版那样"无论分歧多小都整条照搬"。
* 代码：`--selector-mode soft|hard`、`--selector-beta`、`--selector-reliability`。

### ③ logits 上的 MSE → **率域温度 KL + 可靠性加权**

* **ANN 假设**：logits 是连续量、量级稳定，MSE 直接可比。
* **SNN 现实**：脉冲 logits = `fc(平均放电率)`，数值小一个量级且随 T 变化；
  MSE 与尺度强耦合，λ_reg 的物理意义随 T、width 漂移。
* **改造**：默认 `--consistency-loss kl_rate`（温度 τ=2 的 KL，对尺度不敏感），
  并按样本脉冲总数 `n/(T·C·ρ)` 降权——脉冲太少的样本其记忆 logits 基本是噪声。
* 保留 `--consistency-loss mse` 作为 ANN 原版对照。
* 代码：`model.per_sample_distance`。

### ④ 单一时刻的输出 → **时序蒸馏**（ANN 根本没有这一维）

* **ANN 假设**：模型只有"最终输出"这一个监督点。
* **SNN 现实**：决策是 T 个时刻证据累积的结果。同样的平均放电率，
  可以在不同时刻出现——"何时发放"本身就是信息。
* **改造**：额外对**逐 timestep 的 logits** 做 KL（`L_temp = mean_t KL(p_t^T ‖ p_t^S)`），
  让学生不仅匹配"发多少"，还匹配"什么时候发"。
* 代码：`--temporal-weight`、`--temporal-tau`；`backbone.forward_temporal` 返回 `(T,B,K)`。

### ⑤ 没有活动调节 → **稳态阈值校准（homeostatic plasticity）**

* **ANN 假设**：激活不会"死掉"或"饱和"到无法学习。
* **SNN 现实**：持续学习下放电率会**崩塌或爆炸**——新任务的输入把膜电位推向静默，
  或者权重增长让网络饱和。这是脉冲网特有的失败模式，两篇原论文都没有处理。
* 实测（本仓库，width 16、T=4）：
  * 任务 0 开始时全网平均放电率 **0.001**（几乎不发放，梯度信号极小）→ 校准后 **0.052**；
  * 学完任务 0 后升到 **0.385**（过度活跃）→ 任务 1 开始前校准回 **0.089**。
* **可控对照**（单任务 10 类、1500 训练样本、10 epochs、width 32、T=4，只改 `--calibrate`）：

  | 配置 | 训练 CE | class-IL |
  |---|---|---|
  | 不校准 | 1.93 | 30.40 |
  | **校准**（0.001 → 0.065） | **1.57** | **42.00** |

  **单这一项 +11.6 点**，同一 seed、同一预算、其余完全相同。
* **改造**：每个任务开始时测量逐层平均放电率，按 `scale = sqrt(rate / ρ)` 调整
  `v_threshold`（分多轮、有界），把活动拉回目标区间 ρ 后再训练。
* 代码：`--calibrate --rate-target 0.05 --calibrate-rounds 2`。

> 这一条最能说明"不能只换 backbone"：CLS-ER 的两个记忆都在**复制一个几乎不发放的网络**，
> 它的一致性约束、选择器、EMA 全都建立在一个没有信息量的表示之上。
> 网络先要"活着"，CLS 机制才有意义。

### ⑥（附加）近端约束

* CLS-ER 只用 logits 蒸馏约束 working；脉冲网的代理梯度有偏，参数会在噪声方向漂移。
* **改造**：加 `λ_p‖θ_W − θ_stable‖²`，相当于新皮层对海马体快速编码的慢约束。
* 代码：`--proximal-weight`。

## 3. CLS-ER 机制：哪些原样保留

| CLS-ER 组件 | 保留情况 | 代码 |
|---|---|---|
| working / stable / plastic 三模型 | 原样 | `memories.SemanticMemories` |
| EMA 系数调度 `min(1−1/(t+1), α_max)` | 原样 | `_ema_into` |
| 概率触发更新 `rand()<freq` | 原样 | `update()` |
| 选择器语义（用真值类置信度挑记忆） | 保留语义，硬→软 | `select_logits` |
| 一致性损失（Eq.1 第二项） | 保留结构，MSE→率域 KL | `model.observe` |
| reservoir episodic buffer | 原样 | `buffer.ReservoirBuffer` |
| 联合 CE（当前批 + 回放批） | 原样 | `observe` |
| 无 task-id / 无任务边界 | 原样 | — |

**没有引入**：task-id、任务掩码训练、外部教师、梯度投影、网络扩张。

## 4. 一次优化步

```
1. 取当前批 + 回放批（回放可选 poisson 随机编码）
2. 直接编码 (T,B,3,32,32) → SpikingResNet.forward_temporal
   → logits (B,K), logits_t (T,B,K), feats (T,B,C)
3. L_CE = CE(logits, [y_cur | y_buf])
4. 记忆在回放批上给 logits → 软门控融合 z_sel（detach）
   L_cons = Σ w_i · KL_τ( p(z_sel_i) ‖ p(z_cur_i) ) / Σ w_i     ← CLS-ER Eq.(1)
   w_i = |c_s − c_p| · reliability(脉冲数)
5. 可选：L_temp（逐 timestep KL）、L_prox = ‖θ_W − θ_stable‖²、
   L_sparse / L_subspace / L_stab（SD²-SNN）
6. backward / step
7. buffer 写入未增广样本；两次概率触发 EMA（参数 + BN + 阈值）
```

每个任务开始前（可选）做**稳态阈值校准**；每个任务结束后在所有已见任务上评测。

## 5. 评测协议（脉冲网需要额外处理）

* `--eval-passes N`：用 N 次独立随机编码，softmax 概率平均后再取 argmax。
  T 很小时单次前向的方差很大，单次评测会低估且不稳定。
* `--eval-encoding poisson`：评测也可以换成随机编码，与训练时的编码统计一致。
* `class-IL`：所有已见类别取 argmax（CLS-ER 报告的指标）。
* `task-IL`：限定在任务标签空间（官方 `mask_classes` 口径）。
* `forgetting_i = max_{j≥i} acc[j][i] − acc[K][i]`。

## 7. 结果：SNN 原生适配 vs ANN 口径（Seq-CIFAR-10，25 epochs）

同一 seed、同一预算（width 32、T=4、buffer 500、batch 32、25 epochs/task、5 任务 × 2 类），
**唯一差别是 §2 的机制口径**：

| | class-IL | task-IL | F_cil | F_til | BWT |
|---|---|---|---|---|---|
| **SNN 原生**（软门控 + 率域 KL + 整状态 EMA） | **57.50** | **89.00** | **33.49** | **3.91** | **−40.47** |

它满足与脉冲骨干完全相同的接口（`forward` / `features` / `forward_temporal`），
因此模型、双记忆、一致性损失、NCM、校准器全部一行未改。

**归因公式（数字对得上）**

```
论文 CLS-ER（ANN, 50 epochs）              75.22
   │  −9.66  ← 预算与配方（我们只有 25 epochs）
   ▼
稠密 ANN（2.80 M, 25 epochs）               65.56
   │  −8.05  ← 脉冲基底（T=4 直接编码 + 时间平均放电率读出）
   ▼
脉冲 SNN（其余完全相同）                    57.51
─────────────────────────────────────────────
总差距 17.71 = 9.66（预算）+ 8.05（基底）
```

三条结论：

1. **脉冲基底的代价是真实的，但没有想象中大**：相对差距约 12%。之前"脉冲网很差"的印象，
   大部分其实来自预算不足（9.66 点占比更大）。
2. **基底差距主要落在"每个任务的绝对精度"上**，而不全是遗忘：每任务低 2.6–12.9 点，
   而 F_cil 只差 3.9。这解释了为什么此前八条"减少遗忘"的路线（§5）全部无效——
   **它们治的不是主要矛盾**。
3. **我们的 ANN 也只到 65.56，离论文还差 9.66**：这一半与脉冲无关，是 25 vs 50 epochs
   加上简化掉的东西。所以差距有两块，块块都不小。

**由此得到的优化方向**：不再是"减少遗忘"，而是**提高单任务表征质量**——
首推 `--time-steps 8`（SD²-SNN 复现里单任务上限 80.5 → 84.1），其次是 `--width 64`
（把参数提到与论文同规模的 11.2 M）。

> 这一节替换了更早的一个判断。在补上 ANN 对照之前，本 README 曾写道"阻碍来自 logit
> 校准，而不是表征或遗忘"——ANN 对照证明那是错的：同预算下稠密骨干在**每个任务**上都高
> 2.6–12.9 点，基底差距首先是表征质量，logit 校准只是表象。

### 7c 两个基底改进：T=8 与膜电位读出

沿着 §7b 指出的方向试了两条，都是**同一算力口径下的单变量对照**：

| 配置 | class-IL | task-IL | F_cil | 算力 | per-task（末行） |
|---|---|---|---|---|---|
| 放电率 T=4（基线） | 57.51 | 88.98 | 33.49 | 1.00× | [40.2, 31.8, 51.9, 69.8, 94.0] |
| **放电率 T=8** | **58.80** | **90.28** | 33.27 | 2.08× | [41.0, 35.8, 56.0, 66.8, 94.5] |
| **膜电位 T=4**（`--readout membrane`） | **57.96** | 89.37 | 33.32 | **1.23×** | [38.0, 39.3, 49.5, 70.0, 93.1] |
| （参考）稠密 ANN | 65.56 | 92.99 | 29.60 | 0.66× | [49.9, 39.6, 64.8, 77.1, 96.6] |

逐检查点（膜电位 − 放电率 T=4）：**+0.2 / +1.2 / −0.9 / +1.5 / +0.4**，平均 +0.5，不单调。

**T=8 是本项目最好的 SNN 结果（58.80，+1.29），但要 2 倍算力。** 膜电位只在 1.23× 算力下
拿到 +0.45——每点收益的成本更低（0.51× vs 0.83× 算力/点），但绝对量太小。

**一个被直接证伪的假设**：我曾推测"时间平均放电率的量化（T=4 时每维只有 9 个离散取值）
是基底差距的主因，改成连续的膜电位读出就能大幅补回"。实测：

| 读出方式 | 量化档位 | task 0 | 终值 |
|---|---|---|---|
| 放电率 T=4 | 9 | 96.1 | 57.51 |
| 放电率 T=8 | 17 | 97.5 | 58.80 |
| 膜电位 T=4 | 连续 | 96.3 | 57.96 |

**完全连续与 9 档量化几乎等价**（96.3 vs 96.1）。所以 T=8 的收益不是来自"更细的量化"，
而是来自"更多时间步 = 更多实际计算量"。这条否定把"读出信息量"从嫌疑名单上划掉了。

> 实现膜电位读出时踩了一个静默 bug：`self.last_v = v_pre_reset.detach()` 让分类头拿到的
> 是常数，骨干**一个梯度都收不到**，整网退化成"随机特征 + 线性探针"，task 0 只有 64.8。
> 修复后回到 96.3。现在有回归测试逐一检查两种读出下**全部**骨干参数是否都拿到非零梯度——
> 这类断裂从损失曲线上完全看不出来（CE 一路从 1.25 降到 0.65，看起来"在学"）。

**结论**：基底差距 8.05 点里，T=8 补回 1.29、读出方式补回 0.45，**剩下约 6.3 点没有被
任何"改模块"的手段触动**。它更可能来自训练动力学本身（替代梯度的偏差、固定 T 的计算深度
上限），要动它属于换训练范式，超出本项目的范围。

### 7d PLIF：可学习膜时间常数（本项目最划算的改进）

固定 `tau=2` 意味着 17 个 LIF 层用**同一个**时间积分尺度——第一层（原始像素）和最后一层
（抽象特征）的泄漏速度相同。PLIF（Fang et al., ICCV'21）把它改成每层一个可学习标量：

```
1/tau = sigmoid(a)                  # a 每层一个，共 17 个参数
v_t   = (1 - 1/tau) * v_{t-1} + x_t
初始化 a 使 1/tau = 0.5             # 等价于原来的 tau=2，所以是纯可学习化
```

| 配置 | class-IL | task-IL | F_cil | 算力 | 相对基线 |
|---|---|---|---|---|---|
| 基线（固定 τ=2） | 57.51 | 88.98 | 33.49 | 1.00× | — |
| **PLIF（+17 参数）** | **59.66** | **91.55** | 33.49 | 1.51× | **+2.15** |
| 稠密 ANN（参考） | 65.56 | 92.99 | 29.60 | 0.66× | +8.05 |

逐检查点：**+1.7 / +3.1 / −0.1 / +2.4 / +2.2**（五个里四个为正）。

**为什么它有效而别的都无效**：`task-IL` 也从 88.98 涨到 **91.55（+2.57）**——说明改进
不是"重排 logits"，而是表征质量本身变好了。这是唯一一个同时推高两个指标的改动，
补回基底差距的 **27%**，且按"每点收益的算力成本"算是所有手段里最便宜的（0.70× vs T=8 的
0.83× 算力/点）。

### 7e 齿状回模式分离：一个被证伪的诊断

线索是 **task-IL 89 / class-IL 57.5**——每个任务内分得开、跨任务分不开，数学上就是"表征
不够正交"。生物靠齿状回解决：颗粒细胞比皮层输入多一个数量级（扩张），且只有 2–5% 活跃
（稀疏），重叠输入于是得到几乎不重叠的码字。而我们的实测放电率是 **5–40%**，密了一个数量级。

两版实现（都保持约 5% 稀疏）：

| 配置 | 存活单元 | t0 | t1 | class-IL | F_cil | 算力 |
|---|---|---|---|---|---|---|
| 无稀疏（基线） | 256 | 96.1 | 79.0 | **57.51** | 33.49 | 1.00× |
| k-WTA 原地稀疏 | 13 | 94.2 | 77.4 | 56.37 | **32.75** | 1.13× |
| **4× 扩张 + 5% 稀疏** | **51** | **95.6** | **78.8** | 57.41 | 33.29 | 1.57× |

- **扩张修好了"信息量"这一半**：原地稀疏到 13 个单元掉 1.9 点，扩张到 51 个只掉 0.5 点——
  代价随存活数单调减小（13 → 56.37，51 → 57.41，256 → 57.51）。
- **但"正交性收益"始终没出现**：F_cil 只比基线好 0.2–0.7（噪声内），class-IL 持平或略低。

**所以"表征不够正交导致跨任务混淆"这个诊断被证伪。** 把码字压到 5% 稀疏（两两相关性
理论上大幅下降）并没有改善 class-IL——跨任务混淆的成因不是"码字太像"，更可能是分类器
在增长的 softmax 上失效、或特征被新任务的梯度整体推走。

> 这一节也贡献了两个实现 bug 的记录：读出用 `last_v.detach()` 让骨干收不到梯度；
> `forward_temporal` 在扩张模式下把 256 维特征喂给了 1024 维的头。两者现在都有回归测试。

### 7f 组合 PLIF + T=8：62.73，补回基底差距的 65%

两个改进作用在不同维度上（时间常数的**质**、时间步数的**量**），叠加后超可加：

| 配置 | class-IL | task-IL | F_cil | 算力 | 相对基线 |
|---|---|---|---|---|---|
| 基线 T=4 | 57.51 | 88.98 | 33.49 | 1.00× | — |
| PLIF 单独 | 59.66 | 91.55 | 33.49 | 1.51× | +2.15 |
| T=8 单独 | 58.80 | 90.28 | 33.27 | 2.08× | +1.29 |
| **PLIF + T=8** | **62.73** | **92.07** | **30.48** | **2.10×** | **+5.22** |
| 稠密 ANN | 65.56 | 92.99 | 29.60 | 0.66× | +8.05 |

- **超可加**：2.15 + 1.29 = 3.44，组合 5.22，多出 1.8 点。机制上讲得通——PLIF 让每层找到
  合适的时间尺度，T=8 提供更多时间步；**有了合适的 τ，多出来的时间步才用得上**。
- **PLIF 在这个组合里几乎免费**：T=8 单独 225 分钟，组合 227 分钟。

**中间任务的改善是关键**（此前所有方法在 t1/t2 都卡在 22–36）：

| | t0 | **t1** | **t2** | t3 | t4 |
|---|---|---|---|---|---|
| 基线 per-task | 40.2 | 31.8 | 51.9 | 69.8 | 94.0 |
| **组合 per-task** | **42.9** | **42.2** | **62.9** | **71.1** | **94.6** |
| ANN per-task | 49.9 | 39.6 | 64.8 | 77.1 | 96.6 |

**t1 的 42.2 已经超过稠密 ANN 的 39.6**。F_cil 也从 33.49 降到 30.48（ANN 29.60）。

**归因账本更新**：

```
论文 CLS-ER（ANN, 50ep）        75.22
  −9.66   预算/配方
我们的 ANN（25ep, 2.80M）        65.56
  −2.83   脉冲基底   ← 原本 8.05，补回 65%
我们的 SNN（PLIF + T=8）         62.73
```

**"脉冲基底要付 8 点代价"这个结论被推翻了。** 用对架构（可学习 τ + 足够时步），代价只有
2.83 点。这也说明前面那些"改机制"的尝试之所以全部无效，不是任务无解，而是**改错了地方**：
瓶颈在基底的训练动力学，不在持续学习的约束。

### 7g 固定正交分类头（PS-SNN 思路）：同算力下最好，但与 PLIF+T=8 负交互

[PS-SNN](https://link.springer.com/article/10.1038/s41598-026-42970-6)（Sci. Rep. 2026）的论点是：
"多数 SNN-CL 方法每个任务随机初始化分类头并用不平衡数据优化它，导致表征漂移。把可学习分类头
换成**预先定义、固定、两两正交的类中心**，就提供了稳定的优化目标。"

实现只需两行：

```python
nn.init.orthogonal_(fc.weight)        # W Wᵀ = I
fc.weight.requires_grad_(False)       # 并且 parameter_groups 会跳过它
```

| 配置 | class-IL | task-IL | F_cil | 算力 |
|---|---|---|---|---|
| 基线 | 57.51 | 88.98 | 33.49 | 1.00× |
| **固定正交头** | **61.37** | 90.22 | 31.39 | **0.98×** |
| 三者全开（固定头 + PLIF + T=8） | 61.73 | 90.83 | 32.55 | 2.2× |

逐检查点（固定头）：96.7 / 82.2 / 64.9 / 59.1 / 61.4，**五个任务全部优于基线**。

**一个必须记录的弯路**：第一版照论文做了 L2 归一化 + 余弦相似度（`s·cos`），完全学不动——

| 版本 | task 0（6 epoch, 2k 样本） | CE |
|---|---|---|
| 可学习线性头 | 81.25 | 0.64 |
| 冻结正交 + 余弦，s=10 | 52.50 | 3.33 |
| 冻结正交 + 余弦，s=1 | 60.00 | **2.3219 ≈ log 10**（预测恒均匀） |
| **冻结正交 + 不归一化** | **85.50** | 1.05 |

原因：**放电率特征全部非负，而正交中心有正有负**，`cos` 被共同的正向分量主导，各类 logits
几乎相同。论文的设定里特征是可正可负的（膜电位/中心化特征），直接搬过来不成立。
因此 `--fixed-head-norm` 默认为 False。

**负交互**：固定头单独 +3.86、PLIF+T=8 +5.22，相加应是 66.6，但三者全开只有 **61.73**，
比 PLIF+T=8 还低 1.0。逐任务看，掉的是中间任务（t1 −4.5、t2 −7.65），两头反而更好——
因为**两个机制治的是同一个病**：当特征已经足够稳定（T=8 + 可学习 τ），冻结边界不再有好处，
反而阻止了边界跟随改善后的特征。

**实用结论**：算力受限时用固定头（+3.86，零额外算力）；追求最高精度用 PLIF+T=8（+5.22，2.1×）。

### 7h 时序蒸馏：两种对齐方式都无效，损伤集中在中间任务

脉冲网络输出的是**轨迹** `h_1..h_T` 而不是单个 logit 向量。逐时刻 KL 会把"证据晚一步出现"
当成遗忘，所以另实现了 soft-DTW 轨迹对齐（`clser_snn/temporal.py`，Cuturi & Blondel 2017）。

| 配置 | class-IL | task-IL | F_cil | 说明 |
|---|---|---|---|---|
| 基线（不蒸馏） | **57.51** | 88.98 | 33.49 | |
| step（逐时刻 KL，λ=0.5） | 57.05 | 89.72 | 34.53 | −0.46 |
| dtw（soft-DTW，λ=0.5） | **54.70** | 87.08 | 33.03 | −2.81 |
| dtw（λ=0.1） | t2 = 60.1，与 λ=0.5 相同 | | | 不是强度问题 |

- **两种都不行，而且 DTW 比逐时刻 KL 更差。** 这与"允许时间平移应该更好"的直觉相反。
- **λ 差 5 倍给出同一条曲线**（t1 78.2/78.3、t2 60.1/60.1）——排除了"权重没调好"。
- **损伤位置固定：中间任务塌到 17–18**（基线 28.3）。中间任务既要对齐更新的轨迹、又要对齐更旧的，
  每次拉它的梯度方向都不一致。
- 一个实现坑：soft-DTW 在两序列几乎相同时会低于硬最小值，**会给"把 logits 压小"发奖励**；
  现在减去 teacher 的自距离并 clamp。单测断言了核心性质：**时间平移 18.2 ≪ 内容改变 77.6**。

### 7i 配方四连否：容量、预算、正则、优化器都不是答案

为了回答"和论文差 9.66 点差在哪"，把四项可疑因素逐一补上（全部在稠密 ANN 上做，排除脉冲干扰）：

| 假设 | 实验 | class-IL | 结论 |
|---|---|---|---|
| 基线 | ANN 2.8 M / 25ep / AdamW / reg0.75 | **65.56** | — |
| ① 容量 + 预算 | 11.2 M / 50ep | 59.62 | **−5.94** ❌ |
| ② 正则强度 | 同上 + reg 3.0（4×） | **46.50** | **−13.1** ❌ 灾难 |
| ③ 优化器 | 2.8 M / 25ep / **SGD 0.1** + wd 5e-4 | 61.16 | **−4.40** ❌ |
| 对照 | SNN 2.8 M / 25ep | 57.51 | — |
| 对照 | SNN 11.2 M / 50ep | 57.67 | +0.16（2.9× 算力） |

**四种"按论文配方补资源"的做法全部让结果变差。** 逐任务看，加容量/预算/正则都会把早期任务
推塌（t0 从 49.9 掉到 38.5、27.6），把最新任务推高——**多出来的能力 100% 被遗忘吃掉了**。

一条贯穿全项目的规律：

| 改动 | 旧任务 | 新任务 | 净 |
|---|---|---|---|
| 固定正交头 | +3.2 | −1.0 | 早期 +3.86 |
| soft-DTW 对齐 | +3.85 | −5.15 | −0.7 |
| 强正则（3.0） | +3.15 | −4.35 | −0.6 |
| 更大模型 + 更长训练 | **−8.35** | +2.65 | −5.94 |

> 在固定预算下，稳定性与可塑性之间是一条近似 **1:1 的权衡线**。调正则、冻边界、加时序约束
> 都只是在这条线上移动位置；**只有提升表征质量（可学习 τ、更多时间步）才能把整条线抬高**。

### 已有证据汇总

| 对照 | 结果 | 结论 |
|---|---|---|
| §7 主体对照（5 任务 × 25 epochs，收敛预算） | 57.50 vs 39.50 | **SNN 适配 +18.0 class-IL**，决定性 |
| **§7b 稠密骨干对照（同参数同预算）** | **65.56 vs 57.51** | **基底代价 8.05；预算代价 9.66** |
| `--calibrate` 开/关（单任务 10 类，10 epochs） | 30.40 → 42.00 | ⑤ 稳态校准 +11.6（5 任务上无效，见 §5） |
| 放电率（未校准 → 校准后） | 0.001 → 0.065 | 脉冲网开局几乎静默，ANN 机制无从下手 |
| `frac_stable`（ANN 口径） | 前 4 任务恒 0.000 | ① 只 EMA 参数会让 stable 记忆直接失效 |

**必须说清的局限**：§7 的主体对照比较的是**一整套改造（①②③ 捆绑）**，
没有逐项拆开。因此"总共值 +18 点"是可靠的，但"每一项各值多少"还不知道——
那需要再跑 3 组单变量消融（软门控 / 率域 KL / 整状态 EMA 各开一个）。另外只跑了
单个 seed，±1 点以内的差异不应解读。

### 回放比例：2 任务上的"灵丹"在 5 任务上变成负收益

`--minibatch-size` 从项目开始一直对齐 CLS-ER 官方默认的 10（每步回放 10 个旧样本，
旧类只占 24% 的梯度预算）。这一个超参的改动效果如下。

**2 任务、8 epochs（先跑的快验）**

| | t0 | t1 class-IL | 旧任务 | 新任务 | F_cil |
|---|---|---|---|---|---|
| 24% 回放 | 91.5 | 72.00 | 67.4 | 76.6 | 12.07 |
| **1:1 回放** | 93.7 | **77.60** | **76.95** | 78.15 | **8.38** |

看起来是重大突破：旧任务 +9.6、遗忘 −3.7。**但这个结论不能外推。**

**5 任务、25 epochs（正式对照，唯一差别是 `--minibatch-size 32`）**

| | t0 | t1 | t2 | t3 | **t4 class-IL** | task-IL | F_cil |
|---|---|---|---|---|---|---|---|
| 24% 回放 | 96.1 | 79.0 | 64.1 | 55.2 | **57.51** | 88.98 | **33.49** |
| 1:1 回放 | 97.2 | 81.0 | 60.8 | 52.1 | **48.43** | 89.84 | **43.31** |
| 差 | +1.1 | +2.0 | −3.3 | −3.1 | **−9.08** | +0.86 | **+9.82** |

终值 per-task：1:1 是 `[29.2, 20.5, 36.6, 60.7, 95.2]`，基线是 `[40.2, 31.8, 51.9, 69.8, 94.0]`。

**为什么 2 任务的结论是假的**：只有 1 个旧任务时，32 个回放样本能均匀覆盖它
（每类约 16 个），所以"提高回放权重"必然有效。任务数一多，同样的预算被摊到 4 个
旧任务上，**每个旧类每步只剩 2–3 个样本**——信号不是变强而是变碎了。证据是中间任务
受害最重（t1: 22.7 → 16.2，t2: 31.5 → 23.2），而最老任务和最新任务反而都略有提升。

**教训**：在持续学习里，**任务数 ≤ 2 的消融会系统性高估任何"保护旧任务"类改动的收益**。
本项目的 2 任务快验在这个超参上给出了 +5.6 的假信号，5 任务才暴露为 −9.1。

## 8. Logit 校准（已实现，尚未训练验证）

诊断结论（§7）：**task-IL 89.0 / class-IL 57.5**，31 个点全丢在"哪个任务的 logits 更大"
上。因此补了四个后处理校准器，全部是 **`z → a ⊙ z + b` 形式的 logit 变换**，不改网络、
不影响两个记忆（因此不会让 EMA 失配）：

| 组件 | 做什么 | 参数 | 依赖 buffer |
|---|---|---|---|
| **WA** 权重对齐 | `γ = ‖W_new‖/‖W_old‖`，把旧类 logit 放大 γ（等价于缩放分类器行） | 无 | 否 |
| **LA** logit 调整 | `z_i − b_i`，`b_i =` 该类在平衡样本上的平均 logit | 无 | 是 |
| **BiC** 偏置修正 | 旧类 `α·z + β`，在 buffer 上跑 SGD 只学这两个标量 | 2 个 | 是 |
| **Cos** 余弦分类头 | `z = s·⟨x̂, ŵ⟩`，消除类间权重范数漂移 | 1 个（温度） | 否 |

### 用法

```bash
# 逐个开
python scripts/train.py --dataset seq_cifar10 --calib-mode wa
python scripts/train.py --dataset seq_cifar10 --calib-mode la --calib-la-mode mean
python scripts/train.py --dataset seq_cifar10 --calib-mode bic --bic-steps 150
python scripts/train.py --dataset seq_cifar10 --cosine-head --cosine-scale 10

# 全开
python scripts/train.py --dataset seq_cifar10 --calib-mode all
```

每个任务结束时自动重新拟合（`model.end_of_task`），并打印本次生效的变换：
`[calib] scale∈[1.00,2.00], |bias|max=1.35, α=0.87, β=-0.12`。

### 两个必须知道的数学点

1. **LA 的 `prior` 模式在 CIL 里是空操作。** 平衡的类别增量流里每个已见类的先验相同，
   `τ·log π` 是个常数，无法区分任务。真正对 CIL 有用的是 `mean` 模式（减去每类平均
   logit），它直接消灭"新类打分偏高"。两种模式都实现了，默认 `mean`。
2. **WA 与余弦头互斥。** 余弦头把每类权重归一化为单位范数，`γ` 恒等于 1，
   WA 自动退化为空操作（`class_weight_norms` 已做相应处理，不会误报）。

### 实现要点

* 校准器是纯推理侧变换，`state_dict` 里保存，可随 checkpoint 迁移；
* WA 的 γ 默认夹在 **[0.5, 2.0]**，避免某次比值爆炸（单测里验证了夹取行为）；
* BiC 用 buffer 的旧/新类各半构造平衡 batch，只优化 `(log α, β)`；
* `metrics.evaluate_task(calibrator=...)` 在 softmax 前应用变换，多趟随机编码也走同一条路径。

### 验证状态

`tests/smoke_test.py` 的 [D] 段 6 项全部通过：

```

ok  weight aligning: γ=8.00 (clamped to 2.00 when out of range)
ok  logit adjustment: marginal estimator, bias=[-1.5,-1.5,-1.5,4.5], argmax share 1.00 → 0.25
ok  bias correction: α=0.573 β=-1.188, balanced acc 0.50 -> 1.00
ok  cosine head: |z|max=3.17 with scale=10, idempotent install, WA becomes no-op
ok  end_of_task: calibration refit + state round-trip, identity when disabled
```

**还没有跑过真实训练**（按你的要求）。因此"能提升多少"目前没有数字，
需要一次 5 任务对照（`--calib-mode none` vs `all`，各约 2 小时）才能回答。

### 校准实验结果：**三个变体全部为负**（这本身是个结论）

在 seq-cifar10、25 epochs、同 seed、只改校准器的条件下，task 1（学完 2 个任务）的表现：

| 变体 | class-IL | task-IL | per-task | 结论 |
|---|---|---|---|---|
| 基线（无校准） | **79.00** | 89.3 | [74.3, 83.7] | — |
| WA+LA，旧估计器，增广上估 | 76.25 | 89.4 | [67.2, 85.4] | −2.75 |
| WA+LA，旧估计器，干净样本估 | 74.60 | 89.2 | [64.1, 85.2] | −4.40 |
| LA，**新估计器**（边缘均值），增广 | 73.92 | 88.3 | [65.1, 82.8] | −5.08 |

（`cal_wala` 跑完了全程：终值 class-IL 54.74 / task-IL 90.23，仍未追上基线 57.50。）

**两次证伪**：

1. ~~"增广样本的统计量有偏差"~~ → 换成干净样本估**更差**；
2. ~~"估计量形式错了（自置信度 vs 边缘均值）"~~ → 修正后**更差**。

**诊断**：per-task 显示校正把**旧类压得更低**（74.3 → 65.1），而旧类本来就被压制；
即 buffer 上测出的"谁打分偏高"与测试集上的真实排序方向相反。两个可能原因：

* buffer 仅 500 样本（每类 50）且经 reservoir + 重新增广，logit 分布与干净测试集不同；
* 更根本的：脉冲 logits 活在**放电率尺度**上，该尺度随任务增加持续漂移
  （BN 统计、阈值都在变），静态的逐类偏置追不上这种漂移。

**因此不要在这条路上继续投入**。若要解决跨任务偏置，应当换分类器而不是修它
（见下节 NCM），或者在训练期加约束。

## 9. 用 NCM 换掉那个偏置的分类头（已实现，尚未验证）

校准三连负之后，结论很明确：**不要修那个线性头，换掉它**。

`ncm.py` 实现在特征空间做**最近类均值分类**：用 episodic buffer 里每类的特征均值作为
原型，推理时按余弦相似度取最近者。

```
训练：完全不变（CLS-ER 双记忆 + SNN 适配），线性头仍作为训练信号
推理：proto_c = mean_{x∈buffer, y=c} f(x)      # 用当前特征提取器重算
      ŷ = argmax_c cos(f(x), proto_c / ‖proto_c‖)
```

**为什么对症**：原型天然处在同一尺度上，不存在"哪个任务的权重更大"这种跨任务可比性
问题；而我们的诊断正是 task-IL 89.0 / class-IL 57.5 —— 特征够好，坏的是头的可比性。

```bash
python scripts/train.py --dataset seq_cifar10 --epochs 25 --eval-head ncm
python scripts/train.py ... --eval-head ncm --ncm-metric euclidean   # 距离度量可换
```

实现要点：

* 原型**每次评测前用当前模型重算**（特征随任务漂移，iCaRL 也这么做）；
* 不在 buffer 里的类用 `-inf` 屏蔽，避免"没有原型的类抢答"；
* 余弦模式下原型做 L2 归一化，`--ncm-temperature` 只影响 softmax 的多趟平均，
  不影响 argmax。

验证状态（`tests/smoke_test.py` [E] 段）：

```
ok  NCM: 2 prototypes, |proto|∈[1.00,1.00], cosine, absent class masked,
        cosine+euclidean both rank correctly
ok  NCM evaluation: class-IL=100, corrupted prototypes drop to 50
```

第二条特意做了反例：把原型故意改成同一个，准确率从 100 掉到 50（2 类随机），
证明评测路径真的在用原型而不是碰巧。

**尚未跑过真实训练**（按你的要求，改完代码先不跑）。预期：class-IL 应当显著高于
57.5（因为绕开了偏置），但可能低于线性头的 task-IL 89.0（原型是每类一个点，
信息量比分类头少）。真实的取舍要用一次 5 任务跑（约 2.5 小时）才能知道。

> **后续（§10）证明预期要下调**：既然 NCM 只拿回 2.1 点，说明问题不在"头的偏置"，
> 而在"特征没有跨任务结构"。光换头只能拿回很小一部分，必须把约束放进训练。

## 10. 特征侧原型约束（已实现，尚未训练）

这是针对 NCM 那个结论的实现：**把"类原型"从推理时的替代品，变成训练时的约束**。

```
每个训练步：
  1. feats = backbone(spk_all).mean(T)            # 与分类头共享同一特征
  2. proto_c 是每类的 EMA 原型（detach，L2 归一化）
  3. L_proto = CE( cos(feats, proto) / τ , y )    # 当前批 + 回放批都参与
  4. loss += λ_proto · L_proto
  5. 用本步的 detach 特征更新原型：
     proto_c ← m · proto_c + (1-m) · normalize(mean_{x:y=c} f(x))
```

关键点在于：**回放样本也参与这条损失**。旧类样本每次被回放时都被重新拉回它自己的
原型，于是"类别之间的相对位置"被持续维护——这正是 NCM 实验暴露出来的缺失结构。

### 三个实现细节

1. **原型 detach**。原型只作为目标，梯度只流向特征；否则优化器会把特征和原型
   一起塌缩，损失降得很快但毫无用处。
2. **EMA 而非精确均值**（`--proto-momentum`，默认 0.9）。精确均值需要每步遍历
   buffer，代价高；EMA 还顺带让原型平滑，不会随单个 batch 抖动。
3. **缺失类屏蔽**。没有原型的类在 softmax 里是 `-inf`；标签本身没有原型的样本
   直接跳过。因此第一步（还没有任何原型）该损失为 0，第二步才开始生效
   （单测里专门断言了这个"第一步不激活、第二步激活"的行为）。

### 用法

```bash
# 训练时加约束，评测用线性头
python scripts/train.py --dataset seq_cifar10 --epochs 25 --proto-weight 0.5

# 训练时加约束 + 评测换成 NCM（特征被显式优化过，NCM 应该更受益）
python scripts/train.py --dataset seq_cifar10 --epochs 25 \
    --proto-weight 0.5 --eval-head ncm
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--proto-weight` | 0.0 | 吸引项权重；0 = 关闭 |
| `--proto-temp` | 0.1 | 余弦 softmax 温度（1/τ = 10） |
| `--proto-margin-weight` | 0.0 | 类间铰链权重；0 = 关闭 |
| `--proto-margin` | 0.1 | 要求的余弦间隔 m |
| `--proto-min-samples` | 4 | 一个类至少要有这么多 buffer 样本才建原型 |

### 实现过程中修掉的两个真问题

**① EMA 原型在旋转的特征空间里会抵消（曾让第一轮扫描完全无效）。**

最初的更新是 `proto ← m·proto + (1−m)·normalize(class_mean)`。训练早期特征空间旋转很快，
把**来自不同特征空间的归一化方向**做平均会互相抵消。症状：两分类任务的原型损失卡在
**0.70 ≈ log 2**（特征与自己的原型正交），同时 CE 从 0.27 涨到 0.88。
现在改为**每个 epoch 从 buffer 精确重算**（500 样本前向 ≈ 1.6 个 batch），回归测试钉死了这一点：

```
ok  refresh vs EMA: cos(EMA proto, current feats) = -0.013  →  cos(refreshed) = 1.000
```

**② `--proto-weight 0 --proto-margin-weight 0.3` 会静默失效。**

原型记忆原本只在 `proto_weight > 0` 时创建，于是"只开铰链"的配置实际上什么都不做
（实测该组 margin 恒为 0.0000）。现已改为**两者任一为正即创建**，并加了断言。

### 结果：六组约束全部为负（同一个模式）

Seq-CIFAR-10、2 任务、8 epochs、同 seed（基线 w0 与各组唯一差别是约束）：

| 配置 | t0 | **t1 class-IL** | 旧任务 | 新任务 | **F_cil** | proto | hinge |
|---|---|---|---|---|---|---|---|
| **基线（无约束）** | 91.5 | **72.00** | **67.4** | 76.6 | **12.07** | — | — |
| 吸引 λ=0.1 | 94.2 | 71.00 | 63.4 | 78.7 | 15.40 | 0.789 | — |
| 吸引 λ=0.3 | 91.7 | 68.17 | 60.4 | 76.0 | 15.68 | 0.835 | — |
| 吸引 λ=1.0 | 92.7 | 70.00 | 60.1 | 79.9 | 16.28 | 0.699 | — |
| 吸引 0.05 + 铰链 0.1/λ0.1 | 90.7 | 70.45 | 65.2 | 75.8 | 12.77 | 0.795 | 0.076 |
| **铰链 0.5/λ1.0（纯排斥）** | **93.7** | 71.42 | 65.5 | **77.4** | 14.10 | 0.764 | **0.384** |

三条稳定的规律：

1. **约束本身是收敛的**（proto 损失 0.7–0.8，远低于随机 1.39；铰链能从 0.076 涨到 0.384，
   说明它确实咬住了）——不是实现问题；
2. **当前任务一致变好**（t0 91.5 → 最高 94.2；新任务 76.6 → 最高 79.9）；
3. **旧任务一致变差，遗忘一致变重**（F_cil 12.07 → 12.8 / 14.1 / 15.4 / 16.3）。

**因此 `--proto-weight` 与 `--proto-margin-weight` 都推荐取 0。**
这条约束是一个不错的"任务内正则"，但它改变不了跨任务保留——无论类内吸引、
类间排斥、还是两者都有。

### 六次实验后的结论

"在分类目标上做文章"这条路已经走到头：校准（三连负）、换分类器（NCM +2.1）、
加特征约束（六组全负）都没能动到 task-IL 89 与 class-IL 57.5 之间那 31 点。

**回放比例也试过了，而且是负的**（`--minibatch-size 10 → 32`，5 任务终值
48.43 vs 57.51，−9.1）。2 任务快验给出的 +5.6 是"只有一个旧任务"造成的假象，
详见 §7 末尾那一节。

### 全部尝试的汇总（Seq-CIFAR-10，5 任务，25 epochs，单 seed）

| 路线 | class-IL | 相对基线 | 判定 |
|---|---|---|---|
| ANN 口径移植 | 39.50 | −18.0 | 移植失败 |
| **SNN 机制适配（①②③）** | **57.51** | **基准** | **唯一正收益** |
| + logit 校准（WA+LA） | 54.74 | −2.8 | 否定 |
| + NCM 分类头（同权重，免训练） | 59.64 | +2.1 | 边际 |
| + 原型吸引（λ=0.1/0.3/1.0，2 任务快验） | 68.2–71.4 | 全负 | 否定 |
| + 类间铰链（2 任务快验） | 70.5 / 71.4 | 全负 | 否定 |
| + 1:1 回放（5 任务） | 48.43 | −9.1 | 否定 |

所有失败路线都是同一个模式：**让当前任务更好、让旧任务更差**。task-IL 在几乎每个变体里
都稳定在 88–90，而 class-IL 在 48–60 之间波动——**瓶颈始终是"任务之间的可比性"**，
而它既不在分类头（NCM 只 +2.1）、也不在目标函数（六组约束全负）、也不在回放比例
（1:1 更差）上。

## 12. 已知限制

* 所有结论均为**单 seed**；两次同配置全程跑的耗时差（108 vs 152 min）说明机器状态
  会波动，±1 点以内的差异不应解读。
* **任务数 ≤ 2 的消融会高估"保护旧任务"类改动**（§7 末尾的 1:1 回放就是反例：
  2 任务 +5.6，5 任务 −9.1）。任何后续实验都应在 ≥5 任务上验证。
* 与 CLS-ER 原文的对比存在三处口径差异：论文 50 epochs / 我们 25；论文 ANN
  ResNet-18 约 11.2 M / 我们脉冲 width-32 约 2.8 M；论文 3 seed 均值 / 我们单 seed。
* 项目**没有实现非脉冲的 ANN 骨干**，因此无法在"同预算同划分"下测出脉冲基底本身的
  代价，15.6 点的总差距不能全部归因于架构。
* 类别顺序是连续的（0–1, 2–3, …），官方 Mammoth 用固定随机排列。
* 时序蒸馏只用了逐时刻 logits，没有做脉冲串级别的匹配（feature-level spike train KD）。
* 稳态校准按层用一个标量缩放阈值，没有做到神经元级（更接近生物但更贵）。
